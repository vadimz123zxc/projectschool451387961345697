# БитТренер

«БитТренер» — автономный веб-тренажёр для подготовки к компьютерному ЕГЭ по информатике (КЕГЭ).

## Состав проекта

- `index.html` — структура страницы и элементы управления.
- `style.css` — оформление тренажёра.
- `script.js` — генераторы заданий, проверка ответов, подсказки, спринт и статистика.

Проект написан на обычных HTML, CSS и JavaScript. Для запуска сайта не нужны серверная часть, база данных или сторонние библиотеки.

## Запуск

Откройте файл `index.html` в современном браузере. Чтобы опубликовать проект в интернете, можно включить GitHub Pages в настройках репозитория.

## Задания

В текущем варианте есть генераторы для всех 27 номеров и несколько учебных вариантов внутри ряда номеров. Всего предусмотрено 46 шаблонов, включая шесть вариантов заданий по теории игр. Темы номеров 10, 13 и 23 сверены с утверждённой моделью ЕГЭ-2027: маска подсети, подсчёт программ исполнителя и графы соответственно. В №23 есть два тренировочных типа — число путей в ориентированном ациклическом графе и кратчайший путь во взвешенном графе.

Для заданий с исходными данными тренажёр создаёт файлы непосредственно в браузере. В проекте используются TXT, CSV и XML Spreadsheet 2003, который открывается электронными таблицами как файл XLS.

Некоторые дополнительные варианты являются тренировочными моделями по соответствующим темам. Они не выдаются за дословные задания ФИПИ и не заменяют официальный открытый банк заданий.

## Проверка

Перед публикацией новой версии следует:
1. Открыть сайт в браузере и пройти все 27 номеров.
2. Несколько раз сгенерировать каждый вариант и проверить, что условие и ответ меняются согласованно.
3. Скачать каждый создаваемый файл и открыть его в текстовом редакторе или электронной таблице.
4. Сверить вычисления генераторов с независимым ручным расчётом или отдельной программой.

Синтаксическая и браузерная проверка этой рабочей ветки ещё должна быть выполнена перед переносом изменений в основную ветку.
