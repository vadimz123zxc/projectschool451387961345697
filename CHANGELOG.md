# Журнал изменений рабочей версии

Рабочая ветка: `work/ege-2027`.

## Изменения генераторов

- №3 — переделана база данных из связанных таблиц товаров, магазинов и операций.
- №4 — условие Фано использует случайное сообщение и подсчёт длины кодирования по назначенным кодовым словам.
- №5 — обновлён алгоритм построения двоичной записи; добавлена дополнительная тренировочная модель по чётности.
- №6 — добавлены варианты на объединение и пересечение фигур Черепахи с подсчётом целочисленных точек.
- №7 — сохранены варианты для изображения, звука, изменения параметров записи, сканирования и передачи; базовый звук подбирает параметры с целым размером файла.
- №8 — добавлены разные условия на номер слова и состав букв.
- №9 — генераторы CSV с проверкой частот чисел в строках.
- №10 — основная модель заменена на маску подсети по утверждённой спецификации 2027 года; поиск сочетаний букв больше не используется как основной тип этого номера.
- №12 — добавлена машина Тьюринга, редактор строк оставлен как дополнительный тип.
- №14 — исправлен подбор минимальной неизвестной цифры.
- №16 — обновлена модель рекурсивных функций.
- №17 — проверяются соседние пары, содержащие ровно одно двузначное число, с делимостью суммы на минимальное двузначное число файла.
- №18 — стены формируются случайно; таблица динамического программирования учитывает достижимые конечные клетки.
- №19–21 — убраны заранее подставленные запасные ответы; параметры выбираются по найденным выигрышным состояниям.
- №22 — определяется количество процессов, завершившихся за первые 17 мс.
- №23 — вместо подсчёта программ исполнителя добавлен подсчёт путей в ориентированном ациклическом графе из файла.
- №24 — поиск максимального фрагмента с заданным количеством вхождений «2025» и букв Y.
- №25 — перебор чисел по маске и делителю без подстановки ответа с другим делителем.
- №26 — добавлен рейтинг продуктов по срокам хранения; журнал сервера сохранён как дополнительная тренировочная модель.
- №27 — центр кластера выбирается среди реальных точек по минимальной сумме евклидовых расстояний. Ответ записывается одной строкой из двух чисел.

## Что ещё нужно проверить

Перед переносом в основную ветку необходимо проверить синтаксис JavaScript, повторную генерацию каждого типа, корректность ответов независимым расчётом и открытие файлов TXT, CSV и XLS в соответствующих программах. Также нужно проверить поведение страницы в браузере.

Некоторые варианты являются дополнительными учебными моделями по темам КЕГЭ, а не дословными формулировками ФИПИ. При подготовке отчёта это различие нужно сохранить.

## Основание для актуализации

Для сверки следует использовать утверждённые материалы ФИПИ, опубликованные для ЕГЭ 2027 года, а не более ранние документы с пометкой «проект»: https://fipi.ru/ege/demoversii-specifikacii-kodifikatory
